# NEXGEGL Executive Report Layout Rules v1.0

Status: RATIFICATION CANDIDATE

## Visual DNA
Reports must be recognizably NEXGEGL without relying on the logo alone.

Use the repository's canonical logo and colour assets. Do not invent brand colours. Typography must use the canonical brand font when formally ratified; until then, label any working typeface as non-canonical.

## Design principles
- Premium Saudi executive / board-level.
- Deep navy foundation with controlled gold accents.
- High whitespace and strong information hierarchy.
- Decision-first layouts.
- Minimal decoration.
- No generic AI visual style.
- No excessive gradients.
- No decorative clutter.
- No imitation of source-document design.

## KFSA visual grammar
KFSA is a decision system, not decoration.
- Use state colours only for decision states.
- Do not flood pages with status colours.
- Every state badge must have evidence/rationale adjacent or traceable.
- BLOCKED and ALERT must visually differ from KILL/FIX/SCALE.

## Page hierarchy
Each page should communicate one executive message:
1. Section number / label
2. Decision headline
3. One-line implication
4. Evidence / analysis blocks
5. Optional decision badge or gate

## Tables
- Prefer 3–6 columns.
- Use short executive labels.
- Avoid dense spreadsheet aesthetics.
- Distinguish evidence status from decision status.
- Do not use colour alone to communicate meaning.

## Charts
Use charts only when they improve a decision. Every chart needs:
- decision-relevant title;
- source / evidence status;
- unit and time period;
- no invented data;
- no decorative 3D effects.

## Cover
Required:
NEXGEGL logo
Document type
Subject
Confidentiality
Date
Prepared for
Primary evidence / source basis
Method when relevant
Decision status when already determined

## Final Decision page
Must visually prioritize:
VERDICT
CAPITAL / RESOURCE DECISION
STRATEGIC PARTICIPATION
NEXT BEST ACTION
OWNER
PASS GATE
STOP CONDITION

## Source discipline
Source material is content/evidence input only. Never copy a third party's visual identity unless explicitly authorized.

## Output tiers
Internal IC Memo: full depth, typically 10–15 pages.
External Executive Decision Brief: 5–7 pages, controlled disclosure.
Executive One-Page: only when requested; must preserve verdict, evidence gap, risk, decision, owner and next action.
